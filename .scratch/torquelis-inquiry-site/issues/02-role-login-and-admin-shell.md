# 02 — 预置角色登录与后台权限壳层

**What to build:** 让管理员、内容编辑和业务人员使用初始化时生成的随机本地凭据登录简体中文后台，并由服务端权限边界限制不同角色，而不是只在界面隐藏入口。

**Blocked by:** 01 — 可复现的双语应用外壳

**Status:** ready-for-agent

- [ ] 初始化时创建三个预置角色账号、随机哈希密码和数据库会话所需密钥，仓库不包含固定明文凭据。
- [ ] 凭据查看命令只在已确认的本地演示环境中显示账号信息。
- [ ] 未登录访问后台会进入登录流程，登录与退出使用数据库会话并设置必要会话 Cookie。
- [ ] 管理员、内容编辑和业务人员登录后进入各自可访问的简体中文后台壳层。
- [ ] 服务端权限矩阵能够拒绝越权请求，并返回不泄露堆栈或敏感信息的明确反馈。
- [ ] 登录成功与失败形成不含密码或会话值的审计记录。
- [ ] 浏览器测试覆盖三角色登录、退出、未登录访问和至少一个服务端越权请求。
