# 13 — 产品草稿、发布版本与恢复

**What to build:** 让内容编辑在中文后台维护完整的产品公开表示，预览中英文内容后发布不可变版本，并把旧发布版本恢复为新草稿而不直接覆盖当前页面。

**Blocked by:** 02 — 预置角色登录与后台权限壳层；04 — 强类型规格与公英制显示；05 — 产品编号与参考号查找；06 — 商用车型适配查找；08 — 已停产产品与稳定地址

**Status:** ready-for-agent

- [ ] 内容编辑可以维护产品中英文内容、SEO、规格、参考号、适配摘要、状态和替代产品。
- [ ] 产品只有中英文及所有必填公开字段均通过服务端校验后才能发布。
- [ ] 预览使用当前草稿但不会改变前台公开版本或站点地图。
- [ ] 每次发布创建包含完整产品公开表示的不可变发布版本。
- [ ] 恢复旧版本只创建新草稿；再次预览和发布后才改变公开页面。
- [ ] 草稿保存使用乐观并发控制，旧版本保存被拒绝并显示最新修改人和时间。
- [ ] 已发布产品不能硬删除；只有从未发布且无引用和历史的草稿可永久删除。
- [ ] 集成和浏览器测试覆盖缺失语言拒绝、预览、首次发布、再次发布、恢复草稿、重新发布和并发冲突。
