# 04 — 强类型规格与公英制显示

**What to build:** 让四类标准替换件使用各自的强类型规格属性，并让海外采购者在产品详情中可靠切换公制基准值与明确标识的英制换算值。

**Blocked by:** 03 — 双语标准替换件目录

**Status:** ready-for-agent

- [x] 规格属性定义包含数据类型、基准单位、选项、必填性和可筛选性，并由分类决定适用属性。
- [x] 空气、机油、燃油和空调分类采用规格中约定的初始字段集合。
- [x] 可换算数值以公制基准值持久化，英制只作为派生显示；螺纹和接口等文本或枚举不换算。
- [x] 产品详情按分类展示规格表，并明确标识演示性能数据不可用于真实选型或采购。
- [x] 不符合属性类型、单位、枚举或必填规则的数据在服务端被拒绝。
- [x] 单元测试覆盖所有单位换算方向、舍入约定、布尔／枚举／文本字段和四类必填规则。
- [x] 浏览器测试覆盖至少一个产品的公英制切换，刷新后显示状态保持一致。
