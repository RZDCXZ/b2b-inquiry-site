# 完成公开仓库与作品集证据

Status: ready-for-agent

Blocked by: 04

Spec: [Torquelis 询盘演示系统规格](../spec.md)

## Goal

把已完成的本地演示系统整理为陌生人可复现、潜在客户可理解、不会误导为真实商业案例的完整作品集证据。

## Scope

- 完成 GitHub Actions：格式、Lint、类型、全新迁移、单元／集成测试、生产构建和 Playwright。
- 固定演示路径在 Chromium、Firefox、WebKit 的桌面和关键移动视口运行。
- 完成 README：定位、虚构声明、环境要求、setup、开发启动、凭据、重置、常用检查、macOS／Linux／Windows 边界和无开源许可证说明。
- 完成架构说明、模块边界、数据模型、权限矩阵、Excel 字段字典、错误代码、固定演示脚本、素材来源与许可证、已知边界。
- 在干净克隆和全新 Docker 数据卷中验证 setup、启动、演示、重置和测试。
- 核对默认禁止索引和显式公开索引模式。
- 核对页面、PDF、截图和视频中的虚构企业、演示性能数据和模拟通知声明。
- 完成工业编辑风视觉收尾、响应式、键盘冒烟和错误／空状态。
- 采集关键截图，覆盖产品查找、详情／PDF、询盘、通知／分配／报价、Excel 错误／撤销／发布和自动化证据。
- 制作 3–5 分钟主视频：中文旁白与简短中文字幕，屏幕展示英文采购端和中文运营端。
- 完成案例文章，说明问题、方案、业务闭环、技术取舍、可验证结果和生产边界。
- 若需要削减范围，按已约定顺序削减装饰、图表、文章数量和数据数量，保留核心证明链。

## Acceptance Criteria

- Linux CI 全绿，并产出覆盖率和 Playwright 报告。
- 三浏览器桌面与移动固定路径通过；不以 Lighthouse 或 WCAG 分数作为门槛。
- 陌生人按 README 在干净克隆中完成 setup、启动、凭据获取和固定演示。
- 演示重置后所有固定路径可以再次执行，数据库和生成素材回到预定状态。
- 默认环境不可索引；显式公开索引模式的 Canonical、Hreflang、结构化数据和站点地图正确。
- 仓库不包含个人凭据、固定密码、真实客户数据、不明版权素材或未说明的外部依赖。
- README 和案例明确：仅本地演示、虚构企业、演示数据、模拟通知、不承诺生产性能或商业结果、仓库无开源许可证。
- 主视频在 3–5 分钟内串联完整证明链，不退化为页面漫游或代码巡礼。
- 截图和视频不展示客户 Logo、认证徽章、真实品牌产品资料或虚构流量／销售成果。
- 案例文章能够让潜在客户理解可承接的产品化定制服务和不承接的 SaaS／完整 CRM 边界。
- 项目在 macOS 人工演示正常，Linux 自动化正常；Windows 明确标为非完成承诺。

## Testing

- 从全新克隆执行一遍 README 中的所有命令，文档和实际输出必须一致。
- 在无作者环境文件、无已有 Docker 卷和无浏览器缓存的条件下复现固定路径。
- 自动检查仓库敏感信息、失效本地链接、未声明素材和默认索引配置。
- 人工键盘冒烟覆盖前台导航、筛选、询盘和后台关键操作。
- 人工核对主视频和截图的虚构声明、模拟边界和无敏感信息。

## Out of Scope

- 部署演示站、购买域名、配置真实邮件、监控或云备份。
- 正式性能基准、WCAG 认证、SEO 排名或真实转化分析。
- 把仓库改为开源模板或提供产品化 SaaS。
