# 17 — 导入批次撤销与批量发布

**What to build:** 为内容编辑提供可审计的导入批次撤销、重新导入、发布预览与批量发布能力；只有尚未发布且导入后未被人工修改的草稿可以安全撤销，任何冲突都必须阻止整批撤销并给出明确原因。
**Blocked by:** 16
**Status:** ready-for-agent

- [ ] 每次成功导入都有稳定的批次标识，并记录受影响产品及导入前后的草稿版本，以便判断能否撤销。
- [ ] 安全撤销以原子方式恢复导入前已有草稿，并移除本批次新建且之后未产生业务历史的草稿。
- [ ] 任一受影响草稿在导入后被编辑或发布时，整批撤销都会被拒绝，并列出冲突产品编号与原因。
- [ ] 撤销不会修改已经发布的产品版本，也不会破坏产品编号、引用号或车型适配关系的历史一致性。
- [ ] 撤销完成后可重新导入同一工作簿，预览与导入结果保持确定性且不会产生重复记录。
- [ ] 批量发布前展示所选草稿的发布校验结果；只有全部通过时才发布整批，否则不发布任何所选产品。
- [ ] 导入撤销与批量发布均写入审计记录，并覆盖成功、冲突、重复操作和并发操作的自动化测试。
