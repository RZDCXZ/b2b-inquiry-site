# 21 — 公开仓库复现与跨浏览器证据

**What to build:** 把项目整理成可由陌生评审者从干净仓库在本机复现的作品，并用持续集成和浏览器测试证明核心演示路径在主流桌面与移动视口稳定工作。
**Blocked by:** 19, 20
**Status:** ready-for-agent

- [ ] 从干净克隆开始，仅按仓库文档即可安装依赖、生成随机本地账号、初始化数据库、启动应用、运行测试和重置演示数据。
- [ ] 仓库不包含密码、密钥、真实联系人或机器专属绝对路径；示例配置清楚区分必填项、可选项和仅用于显式 SEO 模式的设置。
- [ ] 持续集成执行格式检查、静态检查、类型检查、数据库迁移、单元与集成测试、生产构建及端到端测试。
- [ ] Chromium、Firefox 和 WebKit 的桌面与移动视口均覆盖固定公开浏览、询盘提交、角色登录、询盘跟进、内容发布和导入预览路径。
- [ ] README 说明项目定位、架构边界、角色权限、演示账号生成方式、Excel 模板、测试命令、已知限制和本地展示边界。
- [ ] 仓库记录第三方依赖与展示资产的许可或来源，不声称真实商业运营结果，也不承诺 Windows 原生环境支持。
- [ ] 干净复现检查与跨浏览器测试均产出可保留的通过证据，失败时能够定位到具体演示路径。
