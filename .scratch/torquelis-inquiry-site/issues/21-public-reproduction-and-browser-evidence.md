# 21 — 公开仓库复现与跨浏览器证据

**What to build:** 把项目整理成可由陌生评审者从干净仓库在本机复现的作品，并用持续集成和浏览器测试证明核心演示路径在主流桌面与移动视口稳定工作。
**Blocked by:** 19, 20
**Status:** ready-for-agent

- [x] 从干净克隆开始，仅按仓库文档即可安装依赖、生成随机本地账号、初始化数据库、启动应用、运行测试和重置演示数据。
- [x] 仓库不包含密码、密钥、真实联系人或机器专属绝对路径；示例配置清楚区分必填项、可选项和仅用于显式 SEO 模式的设置。
