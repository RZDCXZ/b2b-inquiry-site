# 22 — 作品集截图、主视频与案例文章

**What to build:** 基于最终可复现版本制作一套可直接放入个人网站的截图、3–5 分钟中文讲解录屏和案例文章，清楚展示问题、关键交互、工程取舍与验证证据。
**Blocked by:** 21
**Status:** ready-for-agent

- [ ] 截图覆盖中英文目录、强类型筛选、车型查找、停产替代、询盘成功回执、业务跟进、内容发布、Excel 错误预览、导入撤销、运营总览与审计记录。
- [ ] 所有截图使用固定演示数据和一致视口，画面中没有随机密码、个人目录、调试信息、真实联系人或未经许可的品牌资产。
- [ ] 主视频时长为 3–5 分钟，以中文讲解并配可读字幕，按公开采购路径、后台处理路径、内容运营路径和工程证据完成连贯演示。
- [ ] 录屏在开头或结尾明确说明 Torquelis、产品、客户与运营数据均为虚构，本项目仅为个人作品集演示且不上线运营。
- [ ] 案例文章说明目标用户、核心问题、范围边界、信息架构、数据与权限模型、关键取舍、测试方式、结果和后续可扩展方向。
- [ ] 案例文章不虚构转化率、客户评价或线上流量，并把“本地可复现”与“生产级上线”清楚区分。
- [ ] 截图、视频成片、字幕和案例文章均有可发布版本，并由一份检查清单确认内容与最终应用版本一致。
