# 12 — 联系、报价与关闭状态机

**What to build:** 让当前负责人通过不可覆盖的跟进记录推进询盘，从首次联系、报价到带关闭结果的关闭，并让管理员在需要时重新打开询盘。

**Blocked by:** 11 — 询盘分配与当前负责人隐私边界

**Status:** ready-for-agent

- [x] 当前负责人可以追加联系、报价、内部备注和更正记录，已保存记录不可编辑或删除。
- [x] 跟进记录保存发生时间、操作人、摘要和可选下一步日期。
- [x] 报价记录额外保存十进制定点金额、USD／EUR／CNY 币种和有效期，但不生成报价单。
- [x] 首次联系将已分配询盘推进到跟进中，首次报价推进到已报价。
- [x] 当前负责人关闭询盘时必须选择成交、未成交或无效。
- [x] 只有管理员可以重新打开已关闭询盘，重新打开后回到已分配并保留全部历史。
- [x] 所有状态与跟进变更形成脱敏审计，旧版本状态操作被乐观并发检查拒绝。
- [x] 状态机单元测试覆盖全部允许／拒绝迁移，浏览器测试串联联系、报价、关闭与重新打开。
