# 16 — Excel 全量错误预览与草稿导入

**What to build:** 让内容编辑使用五工作表 Excel 模板批量新增或更新产品草稿，在执行前一次看到全部跨表错误，修正后以单一事务完成导入而不自动公开。

**Blocked by:** 13 — 产品草稿、发布版本与恢复

**Status:** ready-for-agent

- [x] 提供产品、翻译、规格值、参考号和适配关系五工作表模板及字段说明。
- [x] 产品编号作为跨表身份键；存在即更新草稿，不存在即新增草稿，未出现产品保持不变。
- [x] 预览收集所有工作表错误，而不是遇到首个错误即停止。
- [x] 每条错误包含工作表、行号、字段、稳定错误代码和修正建议，并可下载错误报告。
- [x] 任一错误都会阻止整个导入批次，数据库不出现部分写入。
- [x] 无错误确认后在一个 PostgreSQL 事务中写入草稿和导入批次，不自动改变公开版本。
- [x] 预览和确认之间的数据版本变化会被检测并拒绝过期确认。
- [x] 集成与浏览器测试覆盖新增、更新、跨表缺失、重复编号、规格错误、适配错误、全量报告和原子成功导入。
