# 20 — 默认禁止索引与显式 SEO 模式

**What to build:** 将本地作品集演示默认设为不可索引，并提供只能显式开启的 SEO 演示模式，以展示规范链接、多语言关系、结构化数据和站点地图能力而不误导搜索引擎或真实采购者。
**Blocked by:** 08, 15, 19
**Status:** ready-for-agent

- [ ] 默认模式下所有公开页面输出禁止索引指令，robots 规则阻止抓取，且不暴露可索引的站点地图。
- [ ] SEO 模式只能通过明确配置开启，不能因缺失配置、开发环境差异或请求参数而意外启用。
- [ ] SEO 模式使用 `https://torquelis.example` 生成稳定规范链接，并为实际存在的中英文发布版本输出正确的语言替代关系。
- [ ] SEO 模式为站点组织、已发布产品和已发布文章输出与页面可见内容一致的结构化数据。
- [ ] 站点地图只包含可公开访问的已发布规范地址，不包含草稿、归档内容、后台页面或不存在的语言版本。
- [ ] 产品地址变更和停产替代场景保留唯一规范地址，旧地址的重定向不会形成循环或重复索引入口。
- [ ] 自动化测试分别验证默认禁止索引和显式 SEO 模式，并检查规范链接、语言关系、结构化数据与站点地图。
