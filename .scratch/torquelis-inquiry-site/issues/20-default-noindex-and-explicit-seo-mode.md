# 20 — 默认禁止索引与显式 SEO 模式

**What to build:** 将本地作品集演示默认设为不可索引，并提供只能显式开启的 SEO 演示模式，以展示规范链接、多语言关系、结构化数据和站点地图能力而不误导搜索引擎或真实采购者。
**Blocked by:** 08, 15, 19
**Status:** ready-for-agent

- [x] 默认模式下所有公开页面输出禁止索引指令，robots 规则阻止抓取，且不暴露可索引的站点地图。
- [x] SEO 模式只能通过明确配置开启，不能因缺失配置、开发环境差异或请求参数而意外启用。
- [x] SEO 模式使用 `https://torquelis.example` 生成稳定规范链接，并为实际存在的中英文发布版本输出正确的语言替代关系。
- [x] SEO 模式为站点组织、已发布产品和已发布文章输出与页面可见内容一致的结构化数据。
- [x] 站点地图只包含可公开访问的已发布规范地址，不包含草稿、归档内容、后台页面或不存在的语言版本。
- [x] 产品地址变更和停产替代场景保留唯一规范地址，旧地址的重定向不会形成循环或重复索引入口。
- [x] 自动化测试分别验证默认禁止索引和显式 SEO 模式，并检查规范链接、语言关系、结构化数据与站点地图。

## Comments

- 默认保持私有模式；只有 `TORQUELIS_SEO_MODE=public` 精确匹配时才开启公开 SEO，配置在请求时解析，构建产物不会固化模式。
- 公开模式提供规范链接、实际存在语言的替代关系、Organization/Product/Article JSON-LD 和只包含规范公开内容的动态站点地图；规格 PDF 始终附带 `X-Robots-Tag: noindex`。
- 验证通过：`pnpm check`（81 个单元测试）、完整集成测试（122 个）、默认与公开 SEO 两种生产构建，以及 ticket 相关 E2E 在 6 个浏览器配置上的验证。完整 E2E 运行另有 44 个既有后台登录用例受生产 Server Action 响应流提前关闭影响，166/210 通过；所有 ticket 20 用例均通过。
