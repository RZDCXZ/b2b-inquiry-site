# 08 — 已停产产品与稳定地址

**What to build:** 让历史产品链接继续有用：已停产产品保留页面与规格，可显示替代产品；本地化名称变化时旧地址永久跳转到当前地址。

**Blocked by:** 03 — 双语标准替换件目录

**Status:** ready-for-agent

- [ ] 标准替换件支持草稿、已发布和已停产状态，并可关联一个有效替代产品。
- [ ] 已停产产品保留原产品身份、双语页面和历史规格，不出现在默认在售目录结果中。
- [ ] 已停产页面明确显示状态，并在存在替代产品时提供对应语言链接。
- [ ] 替代关系不能指向自身或形成循环。
- [ ] 本地化名称改变后，旧产品地址永久重定向到同语言当前地址，产品编号仍决定身份。
- [ ] 不存在的产品编号返回资源不存在页面，而不是被名称片段误匹配。
- [ ] 集成与浏览器测试覆盖有／无替代产品、循环拒绝、旧地址重定向和不存在产品。
