# 18 — 运营总览与完整只读审计

**What to build:** 提供按角色收敛的运营总览和不可编辑、不可删除的审计记录，使演示者能证明询盘处理、内容发布与批量导入均可追溯，同时不在审计内容中复制敏感资料。
**Blocked by:** 12, 15, 17
**Status:** ready-for-agent

- [x] 管理员总览展示询盘状态、来源、未分配数量、到期跟进、关闭结果与近期导入批次等可由业务数据重新计算的指标。
- [x] 业务人员只看到本人当前可见的任务和统计；内容编辑只能看到与内容、发布及导入有关的脱敏统计，不能读取询盘正文或通知出站箱。
- [x] 审计覆盖登录、产品和内容发布或恢复、导入与撤销、停产变更、询盘分配与重开、垃圾标记、跟进、报价、关闭及站点设置变更。
- [x] 每条审计记录包含操作者、动作、目标、时间与必要的前后状态摘要，但不复制密码、完整联系方式、询盘正文或报价正文。
- [x] 审计记录按权限查询，支持按操作者、动作、目标类型和时间筛选，且界面与服务端均不提供编辑或删除能力。
- [x] 所有总览指标可从当前业务记录重新计算并与展示值一致，空数据和无权限场景有明确状态。
- [x] 自动化测试覆盖角色隔离、敏感字段缺失、指标重算、筛选以及关键动作产生审计记录。
