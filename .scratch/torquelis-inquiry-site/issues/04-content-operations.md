# 实现内容发布、素材与 Excel 产品运营

Status: ready-for-agent

Blocked by: 03

Spec: [Torquelis 询盘演示系统规格](../spec.md)

## Goal

让内容编辑在中文后台安全维护双语站点内容、产品公开表示和素材，并以可预览、可追踪、可恢复的方式批量导入和发布产品草稿。

## Scope

- 建立核心页面、文章、受限富文本、发布版本、归档状态、素材、导入批次和强类型站点设置。
- 核心页面使用预设版块表单；富文本仅允许标题、段落、列表、链接、图片和强调。
- 产品、分类与核心页面要求中英文均满足校验后发布；文章按语言独立发布。
- 准备 8 个原创文章主题，其中 6 个中英文发布、2 个仅英文。
- 发布产品公开表示、分类、核心页面和文章时创建不可变版本。
- 恢复旧版本只创建新草稿，必须预览并再次发布。
- 实现归档、已停产与有限草稿硬删除规则。
- 实现 JPEG／PNG／WebP 图片和 PDF 资料上传的 MIME、文件签名、体积、安全文件名校验。
- 图片要求中英文替代文本；已发布内容引用素材不可删除；替换资料创建新素材。
- 实现产品、翻译、规格值、参考号和适配关系五工作表 Excel 模板。
- 实现跨表校验、全部错误预览、稳定错误代码、修正建议和错误报告下载。
- 确认导入在单一事务中只更新草稿，不自动公开，未出现产品保持不变。
- 实现未发布且未继续修改草稿的整批撤销。
- 实现发布或后续修改形成导入冲突，并拒绝撤销、列出冲突对象。
- 实现批量预览与发布。
- 实现内容编辑和管理员权限、只读审计日志、数据库可推导总览和强类型站点配置。
- 实现草稿与设置的乐观并发检查。
- 审计覆盖发布／恢复、导入／撤销、停产、素材和设置变更，不复制敏感内容。

## Acceptance Criteria

- 内容编辑可以完成核心页面、产品、分类、文章和素材的维护、预览与发布。
- 核心内容缺任一语言时不能发布；仅英文文章可以发布且不生成中文路由。
- 富文本拒绝脚本、iframe、内嵌样式和未允许 HTML。
- 每次发布形成不可变版本；恢复只产生草稿，重新发布后才改变公开页面。
- 归档内容从前台移除但历史保留；只有无发布、引用和历史的草稿可硬删除。
- 不合规素材根据 MIME、签名或体积被拒绝；引用中的素材不能删除。
- Excel 预览一次报告所有工作表错误，并可下载包含位置、代码和建议的报告。
- 任一错误时数据库不写入部分产品。
- 成功导入只改变草稿；未出现在工作簿的产品保持不变。
- 未发布且未继续修改的导入批次可整批撤销。
- 任一受影响草稿发布或继续修改后，撤销被拒绝并列出冲突产品。
- 批量发布后前台、路由、PDF、SEO 和站点地图按语言规则更新。
- 内容编辑看不到询盘详情和通知内容；管理员可以完成所有内容操作。
- 总览数字可从数据库重算，不包含访问量、转化率或销售额。
- 站点设置只包含已允许字段，环境安全配置无后台编辑入口。

## Testing

- 单元测试覆盖发布资格、富文本白名单、删除规则、导入错误代码和撤销资格。
- 真实 PostgreSQL 集成测试覆盖不可变版本、恢复草稿、导入原子性、批次撤销、导入冲突、素材引用和并发控制。
- Playwright 覆盖错误预览、报告下载、修正导入、整批撤销、再次导入、批量预览和发布。
- Playwright 覆盖缺失语言文章、版本恢复、素材拒绝和引用中的素材删除拒绝。

## Out of Scope

- 通用拖拽页面搭建器、任意 HTML 和第三方 CMS。
- 机器翻译、翻译审批队列和更多语言。
- 云对象存储、病毒扫描服务和真实 CDN。
- 已发布内容逐字段撤销或完整事件溯源。
