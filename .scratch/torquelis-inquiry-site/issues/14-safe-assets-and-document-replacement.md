# 14 — 安全素材管理与资料替换

**What to build:** 让内容编辑安全上传双语产品图片和 PDF 资料，在不破坏已发布版本引用的前提下替换规格资料。

**Blocked by:** 09 — 带演示水印的双语规格 PDF；13 — 产品草稿、发布版本与恢复

**Status:** ready-for-agent

- [ ] 图片只接受 JPEG、PNG、WebP，资料只接受 PDF，并同时检查声明 MIME、文件签名和体积。
- [ ] 上传文件获得安全且不冲突的本地文件名，不能利用原文件名写入非预期位置。
- [ ] 图片必须填写中英文替代文本后才能用于双语已发布内容。
- [ ] 已被已发布版本引用的素材不能直接删除，并返回引用对象说明。
- [ ] 替换产品资料会创建新素材记录并更新草稿关联，不静默覆盖旧文件或旧发布版本。
- [ ] 草稿预览和重新发布后才使用替换资料，当前公开版本在发布前保持不变。
- [ ] 演示重置能够清理临时上传并恢复标准生成素材。
- [ ] 自动化测试覆盖扩展名伪装、错误签名、超限文件、路径型文件名、缺失替代文本、引用删除和资料替换。
