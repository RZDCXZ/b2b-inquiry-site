# 06 — 商用车型适配查找

**What to build:** 让海外采购者按商用车品牌、车型、适用年份、发动机和滤清器分类逐级缩小范围，并从固定业务场景找到唯一标准替换件。

**Blocked by:** 03 — 双语标准替换件目录

**Status:** ready-for-agent

- [ ] 建立虚构商用车品牌、车型、发动机和包含年份范围的适配关系。
- [ ] 级联选择只显示与前序选择存在有效适配关系的后续选项。
- [ ] 年份必须落在适配关系范围内，发动机与车型组合不合法时不返回产品。
- [ ] 查询结果只包含已发布且符合品牌、车型、年份、发动机和分类的标准替换件。
- [ ] 准备一个能够从完整车型条件推导到唯一产品的固定演示场景。
- [ ] 集成测试覆盖年份边界、错误发动机、多个候选和唯一候选。
- [ ] 浏览器测试从空白页面逐级完成固定演示场景，并能进入目标产品详情。
