# 07 — 可分享的分类规格筛选

**What to build:** 让海外采购者在某个滤清器分类中使用该分类的规格属性筛选产品，并通过 URL 保存、刷新和分享完全相同的结果状态。

**Blocked by:** 04 — 强类型规格与公英制显示

**Status:** ready-for-agent

- [x] 每个分类只展示标记为可筛选且属于该分类的规格属性。
- [x] 数值筛选使用公制基准值比较，即使界面当前显示英制。
- [x] 结果按产品编号稳定排序并每页显示 12 项，不提供智能相关性或自定义排序。
- [x] 分类、规格条件、单位和页码均编码到 URL，刷新或复制 URL 后结果一致。
- [x] 无结果时保留筛选条件，并提供清除筛选、编号查找和通用询盘入口。
- [x] 非法、过期或不属于当前分类的 URL 条件得到可理解反馈，不触发未处理错误。
- [x] 集成与浏览器测试覆盖范围筛选、枚举筛选、分页、URL 恢复、公英制显示和无结果状态。
