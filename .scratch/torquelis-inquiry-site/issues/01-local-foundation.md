# 建立可复现的本地应用底座

Status: ready-for-agent

Blocked by: none

Spec: [Torquelis 询盘演示系统规格](../spec.md)

## Goal

建立一个从干净克隆即可运行的模块化单体，为后续产品目录、询盘和内容运营提供真实 PostgreSQL、预置角色认证、确定的多语言路由、审计基础和安全演示重置。

## Scope

- 初始化锁定版本的 Next.js App Router、React、TypeScript、Tailwind CSS、pnpm 与基础质量命令。
- 按产品目录、内容发布、询盘运营、身份权限、通知和站点配置建立模块边界；页面与服务端入口不直接承载跨模块业务规则。
- 使用 Docker Compose 启动本地 PostgreSQL。
- 配置 Prisma、初始迁移和真实 PostgreSQL 测试数据库。
- 配置 Zod 服务端输入边界。
- 配置 Better Auth 邮箱密码和数据库会话，只提供管理员、内容编辑和业务人员预置账号。
- 实现服务端角色授权基础和统一权限拒绝反馈。
- 实现 /en、/zh-cn 和根地址固定重定向，不按浏览器语言跳转。
- 建立工业编辑风的基础字色、布局、后台壳层、短促动效和减少动态效果支持。
- 实现 setup、凭据查看、开发启动、数据库停止和演示重置命令。
- setup 创建本地环境文件、随机会话密钥、随机预置密码、数据库、迁移、基础 fixture 和凭据文件。
- 演示重置验证本地演示数据库身份，拒绝不安全目标。
- 建立 UTC 持久化、前台语言格式和后台 Asia/Shanghai 显示约定。
- 建立审计日志基础接口，但只需覆盖本工单产生的登录和重置相关事件。
- 添加基础错误页、空状态和不泄露堆栈的错误处理。

## Acceptance Criteria

- 新机器安装约定 Node.js、pnpm 和 Docker 后，只需运行 setup 和开发启动命令即可打开应用。
- setup 不要求作者个人账号、云服务或手工创建数据库。
- 管理员、内容编辑和业务人员使用生成的随机密码登录；仓库中没有固定明文密码和会话密钥。
- 凭据查看命令只对已确认的本地演示环境显示账号信息。
- 根地址稳定重定向到英文；/en 和 /zh-cn 均可访问；后台界面为简体中文。
- 未登录访问后台被拒绝；登录角色可进入后台壳层；服务端能够区分三种角色。
- 演示重置对非本地、数据库身份不匹配或缺少演示标记的目标拒绝执行。
- 重置可重复执行，并恢复固定基础账号、站点设置和审计状态。
- 页面具备桌面与移动基础布局、键盘焦点和减少动态效果支持。
- 全新数据库可以从零执行所有迁移。
- README 初稿记录环境要求、本地启动、凭据获取、重置边界和 Windows 非承诺范围。

## Testing

- 单元测试覆盖环境安全判定、角色权限基础矩阵、时间格式和语言路由决策。
- 真实 PostgreSQL 集成测试覆盖全新迁移、会话持久化、预置角色和重置幂等。
- Playwright 覆盖根地址、两种语言、登录、退出、未授权后台和三角色后台壳层。
- 在 macOS 人工验证启动；在 Linux CI 至少验证格式、Lint、类型、迁移、测试和生产构建。

## Out of Scope

- 产品目录业务模型。
- 询盘状态机和通知。
- 内容版本、素材和 Excel 导入。
- 公开部署、云服务和真实邮件。
