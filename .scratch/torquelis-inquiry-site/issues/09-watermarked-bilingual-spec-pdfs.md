# 09 — 带演示水印的双语规格 PDF

**What to build:** 让海外采购者从产品详情下载与当前语言对应的轻量规格 PDF，资料由真实演示数据生成，并始终声明不可用于真实选型或采购。

**Blocked by:** 04 — 强类型规格与公英制显示；05 — 产品编号与参考号查找；06 — 商用车型适配查找

**Status:** ready-for-agent

- [ ] 每个已发布标准替换件可生成英文和简体中文两份 PDF。
- [ ] PDF 包含对应语言名称、产品编号、关键规格、参考号和适配摘要。
- [ ] 所有 PDF 显示演示水印和演示性能数据免责声明，不包含真实认证或检测声明。
- [ ] 下载响应使用安全文件名、正确内容类型和与当前产品／语言一致的内容。
- [ ] 产品资料生成可重复执行，并在演示重置后得到稳定结果。
- [ ] 未发布产品或不存在语言的资料不可公开下载。
- [ ] 自动化测试解析生成结果并验证产品编号、语言、水印和关键字段，浏览器测试验证下载入口。
