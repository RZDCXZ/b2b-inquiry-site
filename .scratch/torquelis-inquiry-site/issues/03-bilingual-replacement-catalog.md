# 03 — 双语标准替换件目录

**What to build:** 让海外采购者在英文或简体中文前台浏览空气、机油、燃油和空调四类标准替换件，并查看由稳定产品编号识别的双语产品详情。

**Blocked by:** 01 — 可复现的双语应用外壳

**Status:** ready-for-agent

- [x] 建立标准替换件、双语内容和四个单层分类的持久化模型，不建立产品变体或分类树。
- [x] 最小演示数据至少覆盖四类产品及中英文名称、摘要和产品编号。
- [x] 中英文目录只展示已发布产品，并按产品编号稳定排序。
- [x] 产品详情以语言无关产品身份读取对应语言内容，并持续标明虚构演示企业。
- [x] 产品地址包含语言、产品编号和本地化名称，语言切换进入同一标准替换件的另一语言页面。
- [x] 数据约束保证标准化后的产品编号全站唯一。
- [x] 集成与浏览器测试覆盖四类目录、双语详情、草稿不可见和同实体语言切换。
