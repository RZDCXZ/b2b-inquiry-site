# 10 — 幂等且可防垃圾的询盘提交

**What to build:** 让海外采购者从产品详情或联系页提交结构化询盘，正常提交获得安全回执和管理员模拟通知，可疑或重复提交得到确定结果而不产生重复业务记录。

**Blocked by:** 02 — 预置角色登录与后台权限壳层；03 — 双语标准替换件目录

**Status:** ready-for-agent

- [ ] 产品询盘最多关联一个标准替换件，通用询盘不关联产品，首版不接受附件。
- [ ] 服务端校验所有必填／选填字段，并自动保存来源页面、产品、界面语言和提交时间。
- [ ] 蜜罐、最短填写时间、速率限制、一次性令牌和简单风险规则共同决定正常或垃圾询盘。
- [ ] 正常提交原子创建待分配询盘和一条面向管理员的通知发件箱记录。
- [ ] 垃圾询盘进入独立隔离区且不产生通知。
- [ ] 提交使用 POST/Redirect/GET；同一令牌重试返回原询盘参考号，不创建第二张询盘或通知。
- [ ] 成功页只显示不可推测的询盘参考号、可选产品编号和通用下一步，不回显联系方式或留言。
- [ ] 单元、集成和浏览器测试覆盖正常、通用、重复、超速、蜜罐和风险提交。
