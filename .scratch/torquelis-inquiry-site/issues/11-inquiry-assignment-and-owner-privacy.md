# 11 — 询盘分配与当前负责人隐私边界

**What to build:** 让管理员把待分配询盘交给业务人员，并确保只有管理员和当前负责人能够查看完整联系信息；重新分配后访问权立即切换且历史仍可追溯。

**Blocked by:** 10 — 幂等且可防垃圾的询盘提交

**Status:** ready-for-agent

- [x] 管理员可以查看待分配询盘并将其分配给一个业务人员。
- [x] 分配原子更新当前负责人、询盘状态、分配历史、审计和负责人通知发件箱。
- [x] 当前负责人可以查看完整联系方式和内部区域，其他业务人员得到服务端权限拒绝。
- [x] 管理员重新分配后，旧负责人立即失去完整访问，新负责人立即获得访问。
- [x] 历史负责人、操作时间和重新分配原因保留，不被当前负责人字段覆盖。
- [x] 内容编辑只能看到脱敏询盘数量，不能打开详情或通知内容。
- [x] 乐观并发检查拒绝基于旧版本的重复分配，并提示最新修改人和时间。
- [x] 集成和浏览器测试覆盖首次分配、重新分配、旧负责人失权、内容编辑越权和并发冲突。
