# 05 — 产品编号与参考号查找

**What to build:** 让知道零件号码的海外采购者按产品编号快速直达标准替换件，或按其他虚构品牌的参考号查看唯一或歧义匹配结果。

**Blocked by:** 03 — 双语标准替换件目录

**Status:** ready-for-agent

- [ ] 产品编号和参考号查找忽略大小写、空格和连字符，但不做编辑距离模糊纠错。
- [ ] 精确产品编号优先于参考号，并直接进入对应语言的产品详情。
- [ ] 参考号记录所属虚构品牌，匹配后始终进入明确标识的结果页。
- [ ] 同一标准化参考号可关联多个产品，歧义结果展示全部匹配项而不擅自选择。
- [ ] 无匹配结果提供修改号码、浏览分类和提交通用询盘的继续路径。
- [ ] 真实 PostgreSQL 测试覆盖唯一产品编号、唯一参考号、歧义参考号、格式差异和无结果。
- [ ] 浏览器测试覆盖直达、唯一参考结果、歧义结果和相似但不相同号码不匹配。
