# 15 — 核心页面、文章与站点设置

**What to build:** 让内容编辑通过预设版块和受限富文本维护双语企业内容，让文章按语言独立发布，并让管理员维护有限且安全的站点设置。

**Blocked by:** 02 — 预置角色登录与后台权限壳层；13 — 产品草稿、发布版本与恢复

**Status:** ready-for-agent

- [x] 首页、贴牌服务、制造与品控、技术资源、关于我们和联系页使用预设强类型版块维护。
- [x] 产品描述和文章富文本只允许标题、段落、列表、链接、图片和强调，拒绝脚本、iframe、内嵌样式和任意 HTML。
- [x] 核心页面必须中英文同时通过校验后发布；文章可按语言独立发布。
- [x] 缺失中文版本的英文文章不生成中文路由，语言切换器明确显示暂无版本。
- [x] 页面和文章发布形成不可变版本，恢复只创建草稿；归档后前台隐藏但历史保留。
- [x] 管理员只能编辑企业中英文名称、联系信息、地址、社交链接、默认 SEO 和模拟通知收件角色。
- [x] 索引、数据库、会话密钥和其他环境安全配置没有后台编辑入口。
- [x] 测试覆盖富文本白名单、双语核心发布、单语文章、版本恢复、归档、设置权限和并发冲突。
