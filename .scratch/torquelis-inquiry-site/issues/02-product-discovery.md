# 实现商用车滤清器产品发现闭环

Status: ready-for-agent

Blocked by: 01

Spec: [Torquelis 询盘演示系统规格](../spec.md)

## Goal

让海外采购者能够通过产品编号、参考号、商用车型或分类规格，在中英文前台找到可信的标准替换件，查看稳定产品详情与双语规格 PDF。

## Scope

- 建立 Product、产品翻译、参考号、四个单层分类、规格属性定义与值、车辆品牌、车型、发动机、适配关系、资料和替代产品模型。
- 每个可供应零件使用唯一产品编号和语言无关 ID，不建立产品变体。
- 实现草稿、已发布、已停产状态和已停产产品的替代关系。
- 实现分类可配置的强类型规格属性，并配置四类初始字段。
- 可换算数值以公制保存，提供标识清楚的英制派生显示；文本和枚举字段不换算。
- 实现产品编号与参考号标准化、产品编号优先、参考号唯一／歧义结果，不实现模糊纠错。
- 实现品牌、车型、年份、发动机和分类级联查找。
- 实现分类规格筛选、稳定产品编号排序、每页 12 项和 URL 持久化。
- 实现无结果恢复动作。
- 实现中英文产品 URL、名称变更后的永久重定向和同实体语言切换。
- 实现产品详情、规格、参考号、适配摘要、相关产品、停产提示与替代产品。
- 生成每个已发布产品的中英文轻量规格 PDF，并带演示水印。
- 准备目标演示 fixture：4 分类、50 产品、6 虚构车辆品牌、12 车型、12 发动机、约 150 适配关系、每产品 2–4 虚构参考号。
- 准备至少一个可由车型、年份、发动机、分类和规格推导到唯一产品的固定路径。
- 实现基础产品 SEO 元数据和默认禁止索引／显式公开索引两种输出行为。

## Acceptance Criteria

- 精确产品编号忽略大小写、空格和连字符后直达唯一详情。
- 参考号始终进入结果页；歧义参考号展示全部匹配，不擅自选取产品。
- 车型级联只显示有效后续选项，并能完成固定唯一产品路径。
- 四类筛选器只显示本分类属性，数值范围查询使用公制基准值。
- 公英制切换不改变数据库值，并在 URL 中保留。
- 结果按产品编号稳定排序，每页 12 项；刷新或分享 URL 保持结果。
- 无结果时保留条件并提供清除、编号查找和通用询盘入口。
- 产品 URL 使用产品编号确定身份；本地化名称修改后旧 URL 永久重定向。
- 已停产产品保留原页面、规格和历史身份，并显示替代产品或明确无替代产品。
- 每个已发布产品都有中英文 PDF，内容对应语言并包含演示水印。
- 所有演示性能数据在页面和 PDF 中声明不可用于真实选型或采购。
- 默认模式不可索引；显式公开索引模式的 Canonical、Hreflang、结构化数据和站点地图只包含有效发布路由。

## Testing

- 单元测试覆盖编号标准化、匹配优先级、歧义参考号、属性类型、单位换算、发布资格和路由生成。
- 真实 PostgreSQL 集成测试覆盖关系约束、车型与规格查询、稳定排序、停产替代和 URL 重定向数据。
- Playwright 覆盖编号直达、歧义参考号、固定车型路径、规格筛选、URL 刷新、公英制、无结果、语言切换和 PDF 下载。
- 测试默认与显式公开索引两种模式。

## Out of Scope

- VIN、全文搜索、智能推荐、模糊编号和自定义排序。
- 分类树、产品变体和多产品 RFQ。
- 内容编辑后台、发布版本和 Excel 导入；本工单可用版本化 seed 提供已发布产品。
- 真实品牌、参数、认证或外部资料。
