# Triage 标签

工程 skills 使用五种标准 triage 角色。本文件将这些角色映射到本仓库 issue tracker 使用的实际标签字符串。

| mattpocock/skills 中的标签 | 本仓库使用的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估该 issue |
| `needs-info` | `needs-info` | 等待报告者提供更多信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可交由无人值守的 agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 不会处理 |

当 skill 提到某个角色时，应使用上表中对应的本仓库标签字符串。

如果本仓库以后更换标签命名，只需编辑表格第二列。
