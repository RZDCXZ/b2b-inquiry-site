# 使用Prisma、Better Auth和分层自动化测试

数据访问采用 Prisma 与 PostgreSQL，复杂目录筛选可通过封装的参数化 SQL 实现，所有外部输入由 Zod 在服务端边界校验；后台使用 Better Auth 的邮箱密码与数据库会话，但角色授权由业务服务端显式执行。测试按 Vitest 领域单元测试、真实 PostgreSQL 集成测试和 Playwright 三浏览器演示路径分层，关键业务规则要求完整分支覆盖而不设置全局覆盖率百分比。该组合减少自制认证与数据库基础设施的安全风险，同时保留复杂查询的逃生口和公开仓库可验证的工程证据；代价是依赖多个工具并增加本地及 CI 运行成本。
